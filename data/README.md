# Data

This directory contains the datasets used in the Customer Churn Prediction project.

## Dataset

The project uses the IBM Telco Customer Churn dataset.

Each row represents a telecommunications customer and contains information about:

- Customer demographics
- Services subscribed
- Contract information
- Billing and payment information
- Customer tenure
- Monthly and total charges
- Churn status

The target variable is:

`Churn`

which indicates whether the customer left the company.
