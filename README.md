# Customer Churn Prediction

End-to-end machine learning project focused on predicting customer churn.

The project follows a structured machine learning workflow including data understanding, exploratory data analysis, preprocessing, model development, evaluation and interpretation.

## Objectives

- Understand the main factors associated with customer churn.
- Explore customer and service-related patterns.
- Build reproducible preprocessing steps.
- Train baseline classification models.
- Compare different machine learning approaches.
- Evaluate model performance using appropriate metrics.
- Interpret the final model.

## Technologies

- Python
- pandas
- NumPy
- Matplotlib
- scikit-learn
- Jupyter
